⚙️ Installation
1️⃣ Clone Repository
git clone <your-repo-url>
cd project-name
2️⃣ Install Dependencies
npm install
3️⃣ Configure Environment Variables
Create a .env file:

PORT=8080
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=test_2

4️⃣ Run the Server
npm run test
Server will start at:

http://localhost:8080
